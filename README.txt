TEAMJUGENDPOMJEE – WEBSITE PACKAGE

Inhalt:
- index.html: komplette responsive Website mit LU / DE / FR Sprachumschaltung
- README.txt: diese Anleitung

So öffnest du die Website:
1. ZIP-Datei entpacken.
2. index.html doppelklicken – sie öffnet sich im Browser.
3. Zum Bearbeiten: Rechtsklick auf index.html > Öffnen mit > Editor / Visual Studio Code.
4. Texte findest du im HTML und im translations-Block am Ende der Datei.
